# BasicSlotMachine
A basic slot machine game built in JavaScript using PixiJS and ES6. It features a 5x3 reel layout, a spin button, and a text area to display winnings, all centered and responsive to screen size. Assets are loaded through a preloader screen that shows loading progress.

Work split into 6 steps:
- Step 1: Project html basic template without pixi
- Step 2: Pixi integration + html rework
- Step 3: Images preload (loader screen)
- Step 4: Data
- Step 5: Game core logic (random selection)
- Step 6: Game core logic (winning conditions)

## Testing
Set `RUN_UNIT_TESTS = true` in data.js and open the browser console to see test results.
Set `SPINS` in data.js directly to select your own default SPINS
